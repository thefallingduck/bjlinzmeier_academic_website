Self-hosted web fonts (the files in assets/dist/font/), derived from the Google Fonts repository:
  Lora, Source Serif 4, Source Code Pro - licensed under the SIL Open Font License 1.1 (see OFL-*.txt here).
The variable fonts were trimmed to weights 400-700 and to Latin / Greek / punctuation / math ranges, then
converted to WOFF2. Source Serif 4 is pinned at optical size 20.
